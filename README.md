# Lakshya

Educational Indian investment-planning and mutual-fund research website. Created by Alok Shukla.

> Status: **Phase 1 complete**. The audit is done, the finance and data engines are tested, and the app shell builds.
> The calculator UI is Phase 2 (Agent 1). Not yet deployed.

## Quick start
```bash
npm ci
npm run check     # lint + typecheck + unit tests + production build
npm run dev       # http://localhost:3000
```
Requires Node ≥ 22.12 (developed on Node 24).
